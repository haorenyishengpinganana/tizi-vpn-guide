## 免费节点是从哪里来的？

网上流传的"免费节点每日更新"列表，来源大致有三类：

- **公开的代理列表**：别人扫描或收集来的开放 HTTP / SOCKS5 代理。
- **试用或分享出来的订阅**：机场的试用节点、被分享出来的订阅链接。
- **个人搭建后公开的节点**：有人自建了 VLESS、Trojan、Shadowsocks 服务器，再把配置公开出来。

列表做得认真与否，关键在于有没有**真实测试**。有的站只是把抓到的配置原样贴出来；有的会实测后再发布。比如[节点手册的免费节点页](https://jiedianshouce.com/free-nodes/)，每批节点都从两台不同出口的服务器各做 10 次 HTTPS 请求和一次固定文件下载，并逐条公开测试证据。

## 为什么免费节点今天能用、明天就失效？

用节点手册公开的数据就能直观看到这一点：

- 他们 2026 年 11 月 9 日这一批，从 **2,936 条**去重后的候选中只完成了 56 条双端测试，复测后最终保留 **26 条**。
- 前一天 11 月 8 日发布的那一批，到 9 日复查时，**有 24 条已经无法通过请求或下载测试**。

也就是说，**几千条候选里只有极少数能用，而能用的那些，一天后大部分也失效了**。原因不难理解：

- **开放代理随时会被关掉**：服务器主人发现后就会关闭，或者 IP 被各大网站拉黑。
- **分享出来的节点很快被挤爆**：成百上千人同时用一个节点，带宽耗尽或者流量额度用完。
- **节点本身就是临时的**：试用节点、测试服务器原本就不打算长期运行。

所以"免费节点每日更新"这件事本身就说明：**免费节点只能临时救急，不能长期依赖。**

## 免费节点安全吗？会不会泄露隐私？

这是最该关心的问题。答案取决于节点用的是什么协议，以及运营者能看到什么。

### HTTP / SOCKS5 免费代理：运营者能看到你访问了哪些网站

公开的免费节点中，相当一部分是 **HTTP 或 SOCKS5 代理**。节点手册 11 月 9 日那批的 26 条里，**25 条是 HTTP 或 SOCKS5**，只有 1 条是 Shadowsocks。

- **HTTP 代理**访问 HTTPS 网站时，用的是 `CONNECT` 方法建立隧道（见 MDN 说明）。网页内容仍然由 TLS 加密，但**代理能看到你连接的是哪个域名和端口**。如果访问的是没有 HTTPS 的网站，代理就能看到全部内容。
- **SOCKS5** 协议本身（RFC 1928）**不提供加密**，它只负责转发连接。
- 不管哪一种，运营者都能记录**你的真实 IP、连接时间和访问的目标**。

### VLESS、Trojan 节点：加密靠 TLS，但运营者仍然可信与否未知

- **Trojan** 先建立一次真实的 TLS 握手，之后的数据都在 TLS 里传输。
- **VLESS** 的官方文档明确说明：VLESS 必须配合 TLS、REALITY 等外层安全传输，或者开启 VLESS Encryption 才算安全。

这些协议可以防止**路上的第三方**看到内容，但**节点的运营者是终点**，你的流量由他转发。免费节点的运营者是谁、会不会记日志，你完全不知道。

### 用免费节点的底线

- **不要用来登录**支付账户、主邮箱、工作后台和任何实名账户。
- **没有 HTTPS 的网站**一律不要输入密码。
- **用完就删**：免费节点的订阅和配置不要长期留在客户端里。
- **求助时注意日志**：发给别人的日志里如果含有 UUID 或订阅令牌，先打码。

## 免费节点怎么导入 Clash？

现在主流的 Clash 系客户端大多基于 **mihomo（Clash.Meta）内核**。导入免费节点通常有两种方式：

1. **直接导入 YAML 配置文件**：下载节点站提供的 `.yaml`，在客户端里"导入配置"。
2. **通过订阅 / 代理集合（proxy-providers）**：填入订阅地址，客户端会定时拉取更新。

用代理集合时建议**开启健康检查**。mihomo 文档里的示例是每 300 秒用 `https://www.gstatic.com/generate_204` 测一次，失效的节点会被自动标记出来，不用手动一个个试：

```yaml
proxy-providers:
  free:
    type: http
    url: "你的订阅地址"
    interval: 3600
    health-check:
      enable: true
      url: https://www.gstatic.com/generate_204
      interval: 300
```

## 免费节点连不上、超时怎么办？

按下面的顺序排查，大部分问题都能找到原因：

1. **先换一个节点试试。** 免费节点最常见的问题就是已经失效，跟你的设置无关。
2. **看一下发布日期。** 一天以前的免费节点列表，大部分节点可能已经失效。
3. **检查协议和客户端是否匹配。** 老版本的客户端可能不支持 VLESS 或 REALITY，需要换用 mihomo 内核的客户端。
4. **检查系统时间。** VMess 节点要求本机时间与真实时间相差不能太多（Xray 要求在 120 秒以内），手机时间不准也会导致连不上。
5. **区分"能连上但很慢"和"完全连不上"。** 能连上但慢，多半是节点被挤爆了，换节点比改设置有用。

## 免费节点和付费机场有什么区别？

| | 免费节点 | 付费机场 |
|---|---|---|
| 稳定性 | 以小时、天计算，随时可能失效 | 运营方有维护节点的动力 |
| 速度 | 多人共用，高峰期很慢 | 视套餐和线路而定 |
| 协议 | 很多是 HTTP / SOCKS5 明文代理 | 通常是 VLESS、Trojan、Shadowsocks 等加密协议 |
| 运营者 | 完全未知 | 至少有网站、客服和付款记录可以追溯 |
| 维护成本 | 每天都要找新节点 | 导入一次订阅即可，客户端自动更新 |
| 风险 | 隐私与安全风险最高 | 机场可能跑路，最好按月付 |

**什么时候值得换付费机场？** 当你每天都需要用（工作、学习、看视频），或者已经开始花时间每天找节点时，付费机场的每月花费通常比你浪费的时间便宜。

## 机场推荐怎么挑？一份通用的选择清单

不管选哪家机场，都建议按这个清单来：

- **先买最短的周期**：月付优先，不要一开始就买年付。机场跑路时，损失的只是一个月。
- **看清退款与试用政策**：有没有试用、多少天内可以退款、退款条件是什么。
- **高峰期实测**：晚上 8 点到 11 点是最拥堵的时段，这个时候还流畅才算真的好用。
- **确认协议与客户端支持**：订阅能不能直接导入你在用的 Clash 或手机客户端。
- **看流量与限速规则**：按流量计费还是不限量，超出后限速还是停用。
- **看售后渠道**：有没有工单或群组，遇到问题能不能找到人。

## 常见问题

**免费节点每天在哪里找？**
优先选择**公开测试方法和测试时间**的节点站，比如上文提到的节点手册。只贴配置、不写测试时间的列表，失效率通常更高。

**免费节点会不会被盗号？**
节点本身不会直接盗你的号，但**HTTP 明文网站上的密码**有可能被运营者看到。用免费节点时不要登录重要账户，这是最简单有效的做法。

**免费 VPN 和免费节点是一回事吗？**
不完全一样。免费 VPN 通常是一个 App，一键连接；免费节点是一份配置，需要导入 Clash 等客户端。两者的共同风险是：**运营者能看到你的连接信息**。

**手机能用免费节点吗？**
可以。安卓可以用 mihomo 内核的 Clash 客户端，iOS 需要支持对应协议的代理 App，导入的方式和电脑上一样。

**机场跑路了怎么办？**
这正是建议月付的原因。跑路后没有什么办法追回费用，所以只买短周期，并且保留一个备用的方案。

**枫叶 Maple Relay 怎么样？**
本站目前把它作为推荐的付费选择，但还没有发布实测数据。最可靠的判断方法是：用最短的周期，在你自己的网络和高峰期实际试一次。
