梯子用着用着突然不行了，最常见的两种情况是：

- **节点全部超时**，测速一片红；
- **客户端显示已连接**，但浏览器就是打不开网页。

别急着重装软件。按下面的顺序排查，**从最常见、最容易检查的原因开始**，大多数问题在前三步就能找到原因。

## 第一步：账号和订阅还有效吗？

这是最常见的原因，却最容易被忽略。

1. **登录机场官网**，看看账号是否过期、流量是否用完。官网打不开的话，先看看机场的公告频道。
2. **更新一次订阅**。机场换了服务器地址，旧的节点就会全部失效，更新订阅才能拿到新的。
3. **看看节点名称**。不少机场在账号到期后，订阅里只剩一两个名字像"已过期""剩余流量 0"的假节点。

账号正常、订阅也是最新的，再往下查。

## 第二步：是所有节点都不行，还是个别节点不行？

在客户端里**对所有节点测一次延迟**：

| 测速结果 | 说明 | 怎么办 |
|---|---|---|
| 个别节点超时 | 节点本身出问题 | 换一个节点 |
| 某一类协议全部超时（比如 hy2 节点全挂） | 你的网络可能在限制这类协议 | 换另一类节点 |
| **所有节点全部超时** | 账号、订阅或本机问题 | 回到第一步，或继续往下查 |

### hy2 节点全挂，其他节点正常？

Hysteria2 走的是 UDP。Hysteria 官方文档提到，中国用户有时会遇到运营商阻断或限速 UDP。如果只是 hy2 节点不行，换成 VLESS、Trojan 这类走 TCP 的节点就好。

### 用的是免费节点？

免费节点失效是常态，通常活不过一两天。换一批新的，或者考虑付费机场。

## 第三步：电脑的系统时间准不准？

这一条很多人想不到。V2Fly 官方文档写明：**VMess 依赖于系统时间，系统的 UTC 时间误差要在 90 秒之内**（跟时区无关）。

时间偏差太大时，VMess 节点会**全部连不上，而且不会有明显的错误提示**。

**怎么修**：在系统设置里打开"自动设置时间"，手动同步一次。Windows 在"设置 → 时间和语言 → 日期和时间"里点"立即同步"。

## 第四步：系统代理有没有被改掉？

客户端显示已连接、节点测速也正常，但浏览器打不开网页，**多半是系统代理的问题**。

- **另一个代理软件也在运行**：同时开着两个梯子客户端，它们会互相改系统代理。只留一个，其他的完全退出。
- **浏览器插件接管了代理**：装了 SwitchyOmega 这类代理插件的话，浏览器会按插件的设置走，不读系统代理。把插件切换成"系统代理"模式，或者暂时停用。
- **客户端设置成了"不改变系统代理"**：v2rayN 的系统代理有三个选项，官方说明日常要选"**自动配置系统代理**"，选"清除系统代理"或"不改变系统代理"都不会帮你设置。

**怎么确认**：Windows 打开"设置 → 网络和 Internet → 代理"，看"使用代理服务器"是否打开，地址是否是 `127.0.0.1` 加客户端的端口。

另外，v2rayN 的官方说明提到：Windows 系统代理本来就只支持 HTTP，不支持 SOCKS，**代理设置里只看到 HTTP 是正常的**。

## 第五步：只有某些软件不走代理？

浏览器正常，但游戏、命令行、微软商店的应用不走代理，这不是梯子坏了：

- **游戏、命令行工具**不读系统代理，需要打开 **Tun 模式**（v2rayN 需要以管理员权限运行）。
- **微软商店（UWP）应用**：Clash Verge Rev 官方文档的解释是，UWP 应用有沙盒机制，默认不能访问本机回环地址。打开"设置 → UWP 工具"，勾选需要的应用并保存即可。

## 第六步：Tun 模式下网络异常？

开了 Tun 模式之后连国内网站都不正常，Clash Verge Rev 官方文档给出的原因是：系统里可能有**多个网卡**，或者网段和配置里的规则冲突。解决办法是打开网络设置，删除多余的虚拟网卡（比如之前装过的其他 VPN 软件留下的）。

另外，客户端的代理菜单显示空白，说明**内核通信失败**，官方建议检查 Windows 防火墙设置。

## 还是不行？最后几招

1. **换个网络试试**：用手机热点连电脑。热点下能用、家里宽带不能用，问题就在网络环境，比如公司或校园网的限制。
2. **把客户端更新到最新版**：机场启用了新协议，旧客户端可能不认识。
3. **看日志**：客户端的日志里通常有具体的错误原因。发给机场客服时，**记得把订阅地址和 UUID 打码**。

## 排查顺序速记

> **账号订阅 → 全部还是个别节点 → 系统时间 → 系统代理 → Tun 和防火墙 → 换网络**
